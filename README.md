## 📁 How to Run This Portfolio Locally

```bash
git clone https://github.com/AmmarAhmed-star/portfolio.git
cd portfolio
# Open index.html in browser
# Make sure profile.jpg is in same folder as index.html
```

**Files in this repo:**
```
portfolio/
  index.html    - Main portfolio page
  profile.jpg   - Profile photo
  README.md     - This file
```

> ⚠️ Important: `profile.jpg` must be in same folder as `index.html`, otherwise photo will not show on GitHub Pages.
